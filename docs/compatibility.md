# 兼容性与验证范围

| 平台 | 0.10.0 后台机制 | 证据 |
| --- | --- | --- |
| Apple Silicon Mac | 系统沙盒禁止网络、Apple Events、Mach服务；CPU运行本地模型 | 两组虚构材料真实后台处理，独立4项复测通过 |
| Intel Mac | 同一流程，提供对应官方推理程序 | 未实机验收 |
| Windows x64 / 本地WorkBuddy等Agent | 主机交付任务到无网卡的离线虚拟机；不另开在线会话 | 代码与控制流已适配，未完成整机验收 |

Mac 可由具备本地执行能力的 Agent 转交支持的任务，无需另行登录 Codex/Claude 命令行客户端。客户端支持情况仍需以实际验收为准。

Windows 需要 Windows 10 2004+、8GB内存、12GB磁盘及硬件虚拟化；系统管理员授权、BIOS或单位策略不能由Skill绕过。原Agent账号不被修改，不需要重新登录另一个在线客户端。

推理程序随完整ZIP提供，首次从ModelScope下载约1.1GB的本地模型。缓存按固定散列核验，任务处理期间不下载组件。模型与运行环境持久复用。

本说明适用于0.10.0完整安装包。支持的处理在本地完成，原件、处理过程中的文本和结果正文均不发送给云端模型。

## 自动性能自检

安装后和版本变化后自动运行虚构表格、零匹配导出与虚构文档。实际调用本地模型，核验身份、原值、新增列及待办段落；不是模拟模型回复。合格结果保存在本机，同一版本/配置可复用，每个任务仍检查当前可用内存和隔离。

8GB内存是适配目标，尚未实机验收。Mac运行前估计可用内存须≥2.5GiB；Windows启动3GiB离线虚拟机前须≥3.5GiB，虚拟机已运行时主机仍须保留0.5GiB，虚拟机内部另作可用内存检查。这些是保守运行门槛，不是所有8GB设备都流畅的承诺。

默认2线程、128逻辑批次/64物理批次、关闭额外权重重排副本；使用固定模型、量化精度和8K上下文，处理进程禁止联网。任务串行；Mac额外监测整个材料处理进程，Windows离线虚拟机固定分配3GiB内存。单次推理监测内存，采样RSS超2GiB或耗时超120秒即停止。首次短材料试跑超过60秒提示较慢，超过180秒不通过。监测不可用、结果不一致或隔离失败也会停止，不能自动切换云端。

实测设备为Apple M5 / 24GiB；8GB物理机、Intel Mac、Windows / WorkBuddy尚未实机验收。主机资源波动和长材料仍可能导致后续任务停止。Windows首次系统管理员授权/重启不能绕过。
