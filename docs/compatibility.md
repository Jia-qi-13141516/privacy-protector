## 保护边界

Windows 的原表和身份映射由本地主机与无网卡的离线环境处理；Mac 由禁止联网的本地进程处理。AI 使用的是用户授权的代号数据；名称替换不能保证不可重识别。

Windows 隔离范围是新打开的独立 WorkBuddy 会话；Mac 则是新启动的 Codex / Claude Code 及子进程，覆盖选定原文件、私有工作目录和处理代码的写保护，不涵盖主机上其他程序、原聊天窗口、屏幕共享或用户主动上传的资料。没有对已被攻陷的操作系统、管理员或硬件攻击提供保护承诺。

首次系统授权、单位设备策略和服务商登录由相应权限方决定。程序不会关闭系统安全设置，也不自动向业务系统提交实名资料。
