# 文档保护

想让 AI 整理谈话记录、会议材料或内部说明，却不愿把姓名和事件细节一起交出去？文档保护沿用表格版的本地处理思路，增加了发送前的脱敏预览。

**选择原件 → 本地脱敏与检查 → Agent 摘要、改写或整理 → 本地核验 → 可选恢复身份 → 确认导出。**

| 功能 | 适用材料 | 输出 |
| --- | --- | --- |
| 表格保护 | XLSX/CSV，统计、筛选、限定新增列 | 本地身份回填后的 Excel |
| 文档保护 | TXT/MD、基础 DOCX、纯文字 PDF | 保留代号或恢复身份的 DOCX/TXT |

在本地窗口补充需要隐藏的姓名、机构、地点和事件短语，再检查完整脱敏稿。只有本人确认后，新的受保护 Agent 会话才能获得 document.txt。任务完成后，本地选择是否回填身份，并核对事实、遗漏与人物关系。

第一版支持正文处理，不复制文件名、作者属性、原始附件等信息，也不保留复杂版式。加密文件、扫描件、图片、宏、外链、修订、批注、脚注等暂不支持；标密材料不进入此流程。PDF 文本提取本身不等于 OCR，边界与提取限制见 [pypdf 官方说明](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)。

规则可能漏掉无标签人名或间接识别线索，人工预览必不可少。获准提供的代号稿仍可能送往云端，代号化不等于不可重识别。程序验证格式与代号完整性，不能证明 AI 解释或摘要准确。

当前为 0.8.0 本地预览功能：macOS 本地文档链路与访问拒绝已用虚构材料验证；Windows 适配已实现并完成控制流测试，实机界面、虚拟机升级以及云端模型端到端使用仍待验证。
