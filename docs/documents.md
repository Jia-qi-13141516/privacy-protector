# 文档保护

文档摘录在本地断网环境运行。用户说任务并选择文件后，本地模型选取原文段落，程序保留原文中的人物关系与期限，生成 Word 和 TXT。正文和处理结果不发送给云端模型。

支持重要原文段落和未完成待办摘录，不支持任意改写或自动决策。选段可能遗漏或误选，导出的文件需由用户核对。选好文件后，处理在后台运行。

支持 UTF-8 TXT/MD、基础 DOCX、纯文字 PDF；正文最多2万字符、单段最多2400字。拒绝标密、加密、扫描、图片、宏、修订/批注、脚注、附件和外部活动内容。输出为干净正文，不复制原文件的作者属性或复杂版式。

人名识别不是百分之百准确。为避免识别遗漏导致正文外传，原文、代号稿和输出始终留在本地，模型推理进程禁止联网。程序不能撤销其他 Agent 或软件已获得的文件权限。
