# 文档保护

0.9.0 默认在本地断网环境运行，不再把脱敏稿交给在线 Agent。用户说任务并选择文件后，程序自动识别内容、提取关键段落、保留原文人物关系、生成 Word 和 TXT。

支持提取式摘要、未完成待办摘录。不是任意改写或自动决策；选段仍可能遗漏或误选。最终文件供用户查看使用，不需要点击许可才开始处理。

支持 UTF-8 TXT/MD、基础 DOCX、纯文字 PDF；正文最多2万字符、单段最多2400字。拒绝标密、加密、扫描、图片、宏、修订/批注、脚注、附件和外部活动内容。输出为干净正文，不复制原文件的作者属性或复杂版式。

人名识别不是百分之百准确。隐私保护不依靠“每个人名都识别对了”这个假设：原文、代号稿和输出始终留在本地，模型推理进程禁止联网。程序不能撤销其他 Agent 或软件已获得的文件权限。
