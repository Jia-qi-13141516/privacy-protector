# 隐私保护Skill

## 安装

两种方式任选一种。

**压缩包**：把“隐私保护Skill.zip”交给本地 Agent，说：“请安装并打开这个隐私保护Skill，根据我的系统配置运行环境。”如果不接受 ZIP，先解压，再让它读取包内 SKILL.md。

**链接**：对本地 Agent 说：“请读取 https://github.com/Jiaqi-Guo-0114/privacy-assistant 的 SKILL.md，下载、校验并安装隐私保护Skill，根据我的系统选择入口。”

Windows 使用独立 WorkBuddy 环境；Mac 使用 Codex 或 Claude Code 命令行及本地选表窗口。Mac 需要 Python 3.9 或更新版本，安装前由 Agent 检查所需依赖。首次系统授权与账号登录由本人完成。网页聊天没有本机执行能力时不能完成安装。

## 使用

1. 在本地窗口选择原表、唯一编号和允许分析的字段。
2. 在受保护的 Agent 窗口说明任务，例如“筛选分数达到40的记录，新增是否跟进和0—3的优先级”。
3. 回到本地窗口核对实名结果，确认生成 Excel，再自行导入业务系统。

Windows 也可先在独立 WorkBuddy 里说任务，由它打开选表窗口。Mac 的实名结果保存在受保护目录，生成后访达会显示文件位置。

原表不要拖进聊天。代号数据经允许后仍可能发送给云端模型，代号化不等于绝对匿名。当前原聊天窗口不会自动受到隔离。

支持 XLSX 首张表和 UTF-8 CSV，以及筛选、“是否跟进”和“优先级”两类新增结果。Windows 完整流程仍待实机验收，Mac 的 Intel 设备及实际云端模型交互仍待验证；首次请用虚构材料。
