# 隐私保护Skill 0.8.0 预览版

把本安装包交给本地 Agent，说：“请安装并打开这个隐私保护Skill。”若不接受 ZIP，先解压，再让它读取包内 SKILL.md。此包新增文档保护；GitHub 旧版链接仍可能下载仅含表格功能的 0.7.0。

## 选择要处理的材料

| 功能 | 输入 | 可以做什么 | 输出 |
| --- | --- | --- | --- |
| 表格保护 | XLSX 首张表、UTF-8 CSV | 统计、筛选，新增是否跟进与优先级，本地回填身份 | Excel |
| 文档保护 | UTF-8 TXT/MD、基础 DOCX、纯文字 PDF | 摘要、改写、整理；本地可选恢复身份 | 干净 Word 正文或 TXT |

首次试用可在本地选择包内 `features/document/虚构练习.txt`，补充隐藏“虚构星河学院”，确认脱敏稿后让 Agent：“请整理为简短工作纪要，保留完成情况与待办事项，不补充新事实，保留已有代号。”

## 文档怎么用

1. 在本地窗口选文档，补充需要隐藏的姓名、机构、地点或事件短语。
2. 检查脱敏稿，必要时删除仍能识别身份的细节。确认后，才进入受保护的 Agent 会话。
3. 说明摘要、改写或整理任务；结果完成后回到本地，选择保留代号或恢复身份。
4. 核对事实、遗漏和人物对应，确认导出。

原件不要拖进聊天。自动规则可能漏掉人名与事件细节；“去掉姓名”不等于无法识别身份。模型仍可能收到获准提供的代号稿，不能外发的材料不进入此流程。

第一版不处理标密材料、扫描件、图片、加密文件、宏、附件、外链、修订、批注及脚注；不保留原始复杂版式。程序能核验代号与文件完整性，不能替人判断摘要是否真实准确。

Windows 由独立 WorkBuddy 里的 Skill 打开本地窗口；Mac 使用新的 Codex / Claude Code 命令行。首次授权与登录由本人完成。Windows 文档流程已接入，但尚无 Windows 实机验收；首次请用虚构材料试用。
