# 隐私保护Skill

用户只需说任务、选文件、查看结果。不要打开旧版向导、功能选项、许可或结果确认窗口，不要求用户切换客户端。当前 Agent 负责转交任务；数据分析在本地断网进程或离线虚拟机完成，不调用云端模型处理原件或代号稿。

## 安装

只读取安装包。在包根目录运行 `scripts/auto_setup.py --agent codex`（当前客户端为 Claude Code / WorkBuddy 时改为 `claude` / `workbuddy`）。Mac 用 Python 3.9+；Windows 用包内 `runtime/python.exe -I -B`。不要追加 `--open`。安装在后台完成，首次下载约 1.1 GB 的本地模型；模型来自 ModelScope 的官方 Qwen 仓库，文件散列固定。Mac 和 Windows/Linux 的推理程序随完整 ZIP 提供。

安装状态只读安装目录 `Settings/background-setup.json`。`background_installation_started` 表示已启动，不等于完成。Windows 首次配置虚拟机仍可能需要操作系统的管理员授权或重启；不能绕过系统策略，也不能把操作系统授权说成已经自动通过。原 Agent 的账号资料不变，不创建第二个在线聊天环境。

## 执行任务

执行安装目录中 `scripts/background.py submit --task "用户的具体任务"`，使用上述对应 Python 入口。文件由本地选择器选择一次，程序自动分流。若用户已明确提供本地路径，可追加 `--input "本地路径"`；不要先打开、预览或读取其内容，不把真实原件作为聊天附件。

把明确的数值条件整理成“字段名 大于等于 阈值”等表达；缺少必要字段或阈值时在原会话问清任务，不打开审批向导。不要静默忽略排序、分组或自定义列等要求；不支持的要求应明确说明。

入口立即返回任务 id。用 `scripts/background.py status --id 任务编号` 查看状态，间隔 10—30 秒，下载阶段适当延长。完成时只返回状态、数量与本地结果路径；把结果链接交给用户，不再打开实名文件、预览稿、映射或日志来替用户“看看”。只有明确为虚构/公开材料的测试才可读取输出核验。

只接收固定任务参数，不向保护区传递任意代码。不要另开联网 Agent、调用外部 MCP、把代号稿发往模型，或以普通聊天上传替代失败的处理。失败由固定错误状态说明；不要静默删去筛选条件或伪造成功。生成文件不等于已导入业务系统。

## 支持的任务

- 表格：XLSX 首张表、UTF-8 CSV。明确的数值比较筛选、按数值升降序、记录数与数量合计/均值，新增统一的“是否跟进”和 0—3 优先级。原业务列名与原值保留在本地，身份按记录代号回填。零匹配正常生成只有表头的结果。
- 文档：TXT/MD、基础 DOCX、纯文字 PDF。本地模型识别人名等片段、选取关键段落，再按原文生成提取式摘要或待办摘录，导出 DOCX/TXT。不是任意改写，也不保证模型选段没有遗漏。默认没有任何正文离开本地；自动识别漏掉姓名也不能导致上传。

正文限 2 万字符，单段不超过 2400 字。扫描件、加密文件、宏、活动内容、修订/批注和标密材料仍会拒绝。身份恢复与文件完整性检查不能代替内容质量判断。查看结果是使用成果，不是程序运行前的反复审批。

本 Skill 保护自身的数据处理流程，不能撤销宿主 Agent 原先取得的文件权限，也不能阻止其他软件或用户主动上传。Mac 使用系统沙盒禁止网络和 IPC；Windows 使用无网卡的离线虚拟机。Windows 与 Intel Mac 的完整实机流程尚未验收；不得声称已在所有平台跑通。
