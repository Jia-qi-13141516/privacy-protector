# 隐私保护Skill

安装或启用时执行插件根目录 `scripts/auto_setup.py --agent codex|claude|workbuddy`，选择当前客户端；Windows 使用包内 `runtime/python.exe -I -B`，macOS 使用本地 Python 3。不要让老师抄命令或编辑配置。完整操作边界见根目录 `SKILL.md`。

默认后台安装与检查，不弹选择或启动同意窗口。只有用户明确要求打开旧版向导时才追加 `--open`；后台检查不使用该参数。Windows 在后台准备持久环境，处理任务时才打开受保护 WorkBuddy。已有环境与登录资料保留。安装开始、文件复制完成不等于隔离就绪；以本地自动验收结果为准。当前宿主聊天窗口不会因此受到隔离。只处理安装包，不读取原表、映射、私有状态文件或实名导出表；失败不能退回不隔离模式。

macOS 使用 Codex 或 Claude Code 命令行入口；先在本地窗口选表，再到受保护的新会话说任务，结果回到本地确认。不要从当前聊天读取用户原表。

旧版向导会根据选定的文件自动识别表格或文档，不要求选择功能。文档须先在本地检查脱敏稿，确认后才进入受保护会话；详细模式见包内 features/。

当前版本尚未通过无人工设置的全自动业务处理验收。安装成功不等于已完成数据处理；不得在失败后让用户把原件上传聊天。
